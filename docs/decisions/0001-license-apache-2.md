# 0001: License the core under Apache-2.0

**Status:** accepted (owner confirmed).

## Decision
The open-source core is licensed under Apache License 2.0.

## Reasoning
- Permissive and widely adopted, which suits community growth.
- Includes an explicit patent grant.
- Compatible with a separate proprietary Enterprise layer built on the core.

## Alternative considered
AGPL-3.0 would discourage closed hosted forks but can deter enterprise adoption and contributions.

## Consequences
Third-party licenses must be preserved. Enterprise code stays in a separate private repository.
